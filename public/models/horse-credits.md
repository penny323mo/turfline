# Horse model

**Horse** by **Quaternius**, from the *Ultimate Animated Animal Pack*.
The rigged and animated mesh is distributed under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

- [Author's pack page](https://quaternius.com/packs/ultimateanimatedanimals.html)
- [Author's Horse listing on Poly Pizza](https://poly.pizza/m/qvTrSG9pZF)
- [Original GLB](https://static.poly.pizza/d37dbc87-ca61-4b2c-a2da-d2f0c4240bef.glb)

This game changes the coat colours at runtime and adds its own saddlecloth, tack, racing silks, and jockey geometry. The horse uses the model's original idle and gallop animations.

`horse.glb` is the original CC0 horse. `horse-mounted.glb` adds the project's original gold-silk number 1 jockey and tack. That standalone file contains two clips, Idle and Gallop, with animated reins and rider posture.
